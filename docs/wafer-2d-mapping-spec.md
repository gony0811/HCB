# 2D Mapping Wafer 사양 (도면 학습 정리)

> 제공된 Wafer 도면(그리드 간 간격 / 위치별 칩 개수)에서 읽어낸 정보를 정리한 문서.
> [Mapping2DWindow](../src/HCB.UI/SUB%20UI/USub01Tab/Mapping2DWindow.xaml)의 **Wafer 타입**
> (원판 위 사각형 그리드 배열) 생성 파라미터의 근거가 된다.
>
> ⚠️ 표기 규칙 — **[측정]** = 도면에서 직접 읽은 값, **[추정]** = 읽은 값으로부터 계산·유추한 값.

---

## 1. 개요

Wafer(실제로는 MasterGlass 성격의 원판)는 **원판 위에 사각형 칩(그리드)이 배열**된 구조다.
도면은 두 부분으로 구성된다.

1. **그리드 간 간격** — 인접 칩(그리드) 사이의 피치/간격과 칩 내부 미세 그리드 구조
2. **위치별 칩 개수** — 원판 위 각 행(row)에 놓인 칩 개수(웨이퍼 맵)

---

## 2. 그리드 간 간격 (칩 피치)

인접한 4개 칩(도면상 노란 사각형)의 경계부를 확대한 상세도에서 읽은 값.

| 항목 | 값 | 구분 | 설명 |
|------|-----|------|------|
| **칩 피치 (Pitch)** | **1100 µm (1.1 mm)** | [측정] | 인접 칩 기준점 간 중심-중심 거리 |
| **칩 본체 (유효 폭)** | **1085 µm** | [측정] | 칩의 실제 그리드/유효 영역 폭 |
| **간격 (Gap / 프레임)** | **15 µm** | [측정] | 칩 경계의 여백(스크라이브/프레임). 각 칩 가장자리에 표기 |
| 검산 | 1085 + 15 = **1100** | [추정] | 유효 폭 + 간격 = 피치 (일치) |

- **노란선 주석**: *"노랑선은 도면상 표시일뿐 실제론 없습니다."*
  → 도면의 노란 사각형(칩 경계선)은 **작도용 가이드**이며 실제 패턴에는 존재하지 않는다.
- 4개 칩 사이의 파란 화살표가 상하·좌우 간격(Gap)을 나타내며, 하단 중앙(4칩이 만나는 지점)을 확대한 것이 상세도다.

> **해석**: 칩은 1.1 mm 피치로 배열되고, 각 칩의 유효 영역은 1085 µm, 칩 사이의 여백은 15 µm.

---

## 3. 칩 내부 미세 그리드

각 칩(사각형) 내부에는 **미세 그리드 패턴**과 **중앙 원형 피듀셜(확대 표시)**이 있다.

| 항목 | 값 | 구분 | 설명 |
|------|-----|------|------|
| 내부 그리드 분할 | 약 **14 × 14** | [측정] | 도면 상단 치수선의 "14 × 14" 표기 기준 |
| 내부 그리드 셀 크기 | 약 **77.5 µm** | [추정] | 1085 µm ÷ 14 ≈ 77.5 µm |
| 중앙 피듀셜 | 원형 마크 | [측정] | 칩 중심의 정렬용 마크(확대 서브그리드로 표시) |

> ⚠️ 내부 그리드 분할 수(14)와 중앙 피듀셜의 정확한 규격/치수는 도면 해상도 한계로 **확인 필요**.

---

## 4. 위치별 칩 개수 (웨이퍼 맵)

원판(원)에 칩이 배열된 맵. 하단에 **notch**(방향 기준)가 있다.
좌측에 표기된 행별 칩 개수(위 → 아래):

| Row | 개수 |
|-----|------|
| 1  | 3  |
| 2  | 7  |
| 3  | 9  |
| 4  | 11 |
| 5  | 11 |
| 6  | 13 |
| 7  | 13 |
| 8  | 13 |
| 9  | 11 |
| 10 | 11 |
| 11 | 9  |
| 12 | 7  |
| 13 | 3  |

- **행 수**: 13
- **최대 열**: 13 (중앙 6~8행)
- **총 칩 수**: **121개** ( 3+7+9+11+11+13+13+13+11+11+9+7+3 )
- **대칭성**: 상하 대칭(팰린드롬) — 행별 개수가 위/아래 완전 대칭
- **notch 위치**: 하단 (원판 방향 기준점)

행별 개수 배열(생성 로직에 그대로 사용 가능):

```
[3, 7, 9, 11, 11, 13, 13, 13, 11, 11, 9, 7, 3]
```

## 5. 원판 기하 추정

| 항목 | 값 | 구분 | 근거 |
|------|-----|------|------|
| 칩 피치 | 1.1 mm | [측정] | §2 |
| 최대 칩 폭 방향 | 13 칩 | [측정] | §4 (중앙 행) |
| 배열 폭/높이 | 약 **14.3 mm** | [추정] | 13 × 1.1 mm = 14.3 mm |
| 원판 유효 직경 | 약 **15 ~ 16 mm** | [추정] | 배열 최외곽 + 여백 (정확값 확인 필요) |

> 기존 시퀀스에서 언급된 **MasterGlass 원점(0,0)** 기반 매핑과 규모가 일치한다
> (수십 mm 급의 소형 원판 = 마스터 글래스 쿠폰).

## 6. 2D Mapping (Wafer 타입) 파라미터 매핑

[GenerateWaferMap](../src/HCB.UI/SUB%20UI/ViewModels/CalibrationTabViewModel.cs)의 입력 파라미터에 대응.

| 툴 파라미터 | 도면 값 | 비고 |
|-------------|---------|------|
| **유효 직경 (D)** | ≈ 15 ~ 16 mm | [추정] — 정확값 확인 필요 |
| **그리드 사이즈 (a)** | 1.085 mm (1085 µm) | 칩 유효 폭 |
| **그리드 간격/Gap (x)** | 0.015 mm (15 µm) | 칩 프레임/스크라이브 |
| **마크 피치 (n)** | (선택) 0.0775 mm ≈ 77.5 µm | 칩 내부 미세 그리드 셀. 또는 칩당 1점이면 피듀셜 중심 |
| 칩 피치(파생) | a + x = **1.1 mm** | 칩 중심-중심 간격 |

> **참고**: 현재 `GenerateWaferMap`은 "셀이 원 안에 완전히 포함될 때만" 배열하는 **원형 포함 방식**이다.
> 도면의 **행별 개수 배열([3,7,9,…])** 은 실제 웨이퍼 맵과 정확히 일치하므로,
> 필요 시 이 배열을 직접 사용하도록 생성 로직을 전환하면 실제 칩 배치를 100% 재현할 수 있다.

---

## 7. 확인 필요 항목

- [ ] 원판 **유효 직경**의 정확한 수치 (도면 상단 전체 치수)
- [ ] 칩 내부 미세 그리드 **분할 수(14?)** 와 셀 치수
- [ ] 중앙 **피듀셜 마크**의 규격(형상/크기)
- [ ] `15 µm` 여백이 **칩당 편측인지 양측 합인지** (본 문서는 편측=프레임으로 해석, 1085+15=1100 검산 일치)
- [ ] 웨이퍼 맵 생성 시 **원형 포함 방식** vs **행별 개수 배열** 중 채택할 방식
