2. 모델 등록창 개선 
📷 등록 을 누르면 열리는 창입니다. 모든 마크 등록에 공통 적용됩니다.  
 
개선 내용 3 가지 
① 크롭 미리보기에 크로스라인 표시 
미리보기 중앙에 십자선이 표시됩니다. 
이 교차점이 곧 "검출 시 반환되는 위치"입니다. 
등록하려는 마크의 중심을 이 십자에 맞추십시오. 
체크박스로 표시를 끌 수 있습니다. 
② 확대 / 축소 
• 
미리보기 위에서 마우스 휠, 또는 [−] [+] [맞춤] 버튼 
• 
100% ~ 800% 

==== PAGE 5 ====
• 
확대 시 픽셀을 보간 없이 그대로 표시 → 몇 px 어긋났는지 눈으로 확인 가능 
③ ROI 정밀 조정 
• 
◀ ▲ ▼ ▶ 버튼 또는 키보드 방향키 (Shift = 10 배) 
• 
스텝 1 / 5 / 10 px 선택 
• 
가운데 ↺ = ROI 초기화 
왜 필요한가: 왼쪽 큰 뷰어는 원본을 축소해서 보여주므로 화면 1px 이 이미지 여러 px 입니다. 
마우스 드래그로는 1px 단위 정렬이 불가능합니다. 
확대해서 어긋남을 확인 → 방향키로 1px 씩 보정 하는 순서로 사용하십시오. 
참고 — 스크라이브 등록 시 
Threshold 중앙 정렬 은 자동으로 꺼지고 잠깁니다. 
스크라이브는 선이 ROI 밖까지 이어져 자동 중앙정렬이 성립하지 않기 때문입니다. 
크로스라인에 맞춰 수동으로 정렬하십시오.
